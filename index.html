풀고 싶은 문제

기능은 많은데 무엇부터 해야 할지 모르는 앱, 숫자만 보여주고 결정은 돕지 않는 대시보드. 이런 앱의 흐름을 다시 짭니다.

역량

  • 가설 캔버스, 설문, Journey Map으로 문제 정의
  • Figma 변수와 컴포넌트로 디자인 시스템 구축
  • HTML, React Native로 직접 구현하고 배포

일하는 원칙

  • 자동으로 결정하지 않고 사용자가 확정하게 둠
  • 범위를 좁혀서 먼저 출시하고 검증
  • 목업과 구현을 화면 단위로 대조해 맞춤
